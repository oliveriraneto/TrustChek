# TrustChek 🔍

Um projeto inspirado na interface do Google, mas criado para um objetivo diferente: **verificar se um link é confiável ou potencialmente perigoso**.
O sistema permite que o usuário cole uma URL e receba uma análise de segurança do link.

---

# 📌 Sobre o Projeto

O **TrustChek** é uma aplicação web desenvolvida com:

* HTML
* CSS
* JavaScript
* Node.js

A interface foi inspirada no visual simples e limpo do Google, focando em facilidade de uso e rapidez na verificação de links.

O objetivo principal é ajudar usuários a identificar possíveis:

* Sites falsos
* Links maliciosos
* Tentativas de phishing
* URLs suspeitas

---

# 🚀 Funcionalidades

✅ Interface simples e intuitiva
✅ Campo para inserir URLs
✅ Verificação de confiabilidade do link

# 🔍 Como Funciona

1. O usuário cola um link no campo de pesquisa.
2. O frontend envia a URL para o servidor Node.js.
3. O backend faz a análise do link.
4. O sistema retorna se o link parece:

   * Seguro ✅
   * Suspeito ⚠️
   * Perigoso ❌
